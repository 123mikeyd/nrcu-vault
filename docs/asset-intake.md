# Adding future character material

1. Choose the existing character slug or create a new one under `assets/characters/`.
2. Put supplied originals in `source/` without editing them.
3. Put accepted generated images in `variations/` using descriptive lowercase names.
4. Update the character manifest with contributor, source and generation provenance.
5. Link the asset pack from the character's page in `characters/`.
6. Keep model weights, secrets, caches and private local paths out of the repository.

If a new source conflicts with established character canon, preserve it as an explicitly labelled variant until the maintainers decide whether to promote it.
