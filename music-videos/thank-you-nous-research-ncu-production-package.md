## Production facts stated by the bundle

The supplied README and prompt source explicitly describe the package as:

- a **35-shot**, **five-movement** production plan for one approximately **1:41** wordless film;
- a hand-painted 1990s prestige-anime visual direction rather than photoreal imagery;
- a workflow with diegetic sound/Foley notes but no non-diegetic music prompts;
- a plan whose individual reference-generation shots require user-selected visual references.

These are production-document statements, not independent claims about real people or canonical NRCU history.

The raw ZIP and its offline HTML/source documents are preserved outside normal Git history. The public vault keeps this catalog record and the bundle's recorded live-artifact links rather than duplicating the full package or any embedded/referenced personal images.
