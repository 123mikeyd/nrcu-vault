# Production Assets

Reusable source material and generated variations live here. Existing lore remains in `characters/`, while this directory holds media used to create scenes and videos.

```text
assets/characters/<character>/
├── source/       # supplied sheets and references
├── variations/   # approved generated poses, scenes and looks
├── README.md
└── manifest.yaml
```

Add future character material under the matching slug. Keep source references separate from generated variations, use descriptive lowercase filenames, and record provenance in one manifest per character.
