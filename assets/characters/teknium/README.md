# Teknium production assets

Reusable Teknium references and generated keyframes for NRCU productions.

- `source/teknium-character-sheet.jpeg` — source reference supplied by Sahil.
- `variations/` — controlled identity, action, advert and portal-sequence keyframes.

## Canon note

The current character page describes Teknium's eye piece as connected triangular shades and explicitly distinguishes it from a visor. The supplied production sheet and these generated variations use a red angular eye piece that reads visually as a visor. They are therefore recorded as an **alternate production interpretation**, not a replacement for repository canon. A maintainer can promote or revise that interpretation separately.
