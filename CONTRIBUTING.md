# Contributing

- Work in a fork and submit focused pull requests.
- Preserve existing lore and links; label alternate interpretations instead of silently replacing canon.
- Store reusable character media under `assets/characters/<slug>/`.
- Store finished projects and their selected source takes under `productions/<slug>/`.
- Use lowercase descriptive filenames with version suffixes where needed.
- Add one manifest per character pack or production rather than a sidecar for every file.
- Include contributor attribution and generation provenance.
- Do not commit secrets, model weights, caches, private local paths or unlicensed third-party media.
- Keep individual media files below GitHub's 100 MB file limit.
