# Teknium Portal Sequence

A working NRCU production used to develop the shared character, multi-shot video and audio pipeline.

| Version | Result | Notes |
|---|---|---|
| [`v1/`](./v1/) | 23.8-second continuity proof | Stable character/location, but only three slow beats |
| [`v2/`](./v2/) | 29.1-second revised film | Eight shots, stronger action, varied coverage and mastered audio |
| [`experiments/`](./experiments/) | Controlled tests | FL2VA, Ref2VA and FastH3 comparisons |

Reusable keyframes live in [`assets/characters/teknium/variations`](../../assets/characters/teknium/variations/). Reproducible example scripts live in [`pipeline/examples/teknium`](../../pipeline/examples/teknium/).
